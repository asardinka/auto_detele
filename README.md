# AutoDelete — автоочистка папок `day` / `week` / `year`

Раскладываете скачанное по трём папкам, а скрипт сам удаляет оттуда файлы,
когда выйдет срок. Ничего не висит в памяти: раз в час планировщик Windows
будит скрипт, он отрабатывает доли секунды и завершается.

## Установка

1. Скопируйте `AutoDelete.ps1` и `AutoDelete.cmd` в ту папку, которую хотите
   чистить (обычно `C:\Users\<вы>\Downloads`).
2. Двойной клик по **`AutoDelete.cmd`**.
3. Мастер спросит три вещи (лог, уведомления, Корзина), создаст рядом
   `day`, `week`, `year` и поставит автозапуск.

Права администратора не нужны. Папку с настройками можно переносить целиком —
достаточно потом ещё раз запустить `AutoDelete.cmd`.

## Сроки

| Папка  | Файл удаляется через |
|--------|----------------------|
| `day`  | 1 день               |
| `week` | 7 дней               |
| `year` | 365 дней             |

Сроки меняются в меню (пункт «Изменить сроки хранения»).

**Отсчёт обнуляется**, если объект тронули:

```
удалить, когда:  max(попал в папку, последнее изменение) + срок
```

* правка содержимого файла — срок заново;
* переименование — срок заново;
* **правка любого файла внутри вложенной папки обнуляет срок всей этой папки**;
* просто открыть и посмотреть файл — не считается изменением.

Папка, положенная в `day`/`week`/`year`, считается **одним объектом** и удаляется
целиком вместе с содержимым.

Файл, перенесённый в папку из другого места, получает полный срок с момента
переноса, даже если сам он старый.

## Меню

Повторный запуск `AutoDelete.cmd` показывает статус и меню:

| Пункт | Что делает |
|---|---|
| 1 | лог / уведомления / Корзина |
| 2 | сроки хранения по каждой папке |
| 3 | **Остановить навсегда** — снять автозапуск (настройки и сроки сохраняются) или включить обратно |
| 4 | прогнать очистку прямо сейчас |
| 5 | показать, что попадёт под удаление, ничего не трогая |
| 6 | последние 30 строк лога |

После «Остановить навсегда» скрипт не работает до тех пор, пока вы сами не
запустите `AutoDelete.cmd` ещё раз — тогда он предложит включиться, и
накопленные сроки не потеряются.

## Ключи командной строки

```powershell
.\AutoDelete.ps1              # меню
.\AutoDelete.ps1 -Run         # тихая очистка (так её запускает планировщик)
.\AutoDelete.ps1 -Run -DryRun # показать, что удалилось бы
.\AutoDelete.ps1 -Install     # поставить автозапуск без вопросов
.\AutoDelete.ps1 -Uninstall   # снять автозапуск
```

## Что где лежит

Всё служебное — в скрытой папке `.autodelete` рядом со скриптом:

| Файл | Зачем |
|---|---|
| `config.json` | настройки и сроки |
| `state.json` | когда какой объект появился в папке |
| `autodelete.log` | что и когда удалено |
| `run-hidden.vbs` | тихий запуск без вспышки консоли |

## Что никогда не удаляется

Скрипт трогает **только объекты верхнего уровня внутри `day`, `week`, `year`**
и ничего за их пределами. Служебная папка `.autodelete` (а с ней лог, настройки
и состояние) лежит в корне рядом с ними, а не внутри — под очистку не попадает.
Дополнительно всегда пропускаются недокачанные файлы (`.crdownload`, `.part`,
`.partial`, `.tmp`, `.!ut`, `.download`) и `desktop.ini` / `thumbs.db`.

## Если что-то сломалось

**Удалили `config.json`** — скрипт молча выходит, **ничего не удаляя**. Сроки
в `state.json` целы. Запустите `AutoDelete.cmd`, ответьте на вопросы мастера —
всё продолжит работать с прежними сроками.

**Удалили `state.json`** — все объекты получают полный срок заново. Ошибка всегда
в безопасную сторону: «удалить позже», никогда не «удалить раньше».

**Повредили `config.json` или `state.json`** — файл переименовывается в
`*.bad-<дата>`, дальше как если бы его не было.

**Удалили `AutoDelete.ps1`, папка осталась** — задача в планировщике при
следующем запуске обнаружит пропажу и **снимет себя сама**.

**Удалили всю папку** — задача просто перестаёт что-либо делать. Убрать её запись:

```powershell
Get-ScheduledTask AutoDelete-* | Unregister-ScheduledTask -Confirm:$false
```

(в описании задачи записан путь к папке, по нему её легко опознать).

**Файл занят другим процессом** — строка об ошибке в логе, попытка повторится
через час.

## Мелочи

* Удаление идёт в Корзину. Windows отправляет мимо Корзины файлы, которые в неё
  не помещаются, — такие удаляются сразу и безвозвратно. Если это не нужно,
  отключите Корзину в настройках: тогда удаление всегда безвозвратное и явное.
* Скрипт написан на Windows PowerShell 5.1 — он встроен в Windows, ставить
  ничего не надо.
* Задача называется `AutoDelete-<хеш пути>`, поэтому копии в разных папках
  не конфликтуют.
